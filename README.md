## SEO ownership
Homepage primary keyword: `water damage restoration hollywood fl`.

Specific services and neighborhood/service combinations have separate intent. Do not create additional exact-match doorway pages for `near me`, 954 or 754.

## Editing
Change phone/email/business data in `src/_data/contact.json` and `src/_data/business.json`. Services, causes, neighborhoods, ZIPs and area codes are separate JSON files.

## Build
`node build.js` generates `_site/`. The included site is already generated for deployment.

## Cloudflare Pages

## Important verification before launch
1. Verify that the public address is actually appropriate for the referral campaign. If it is not a real public business location, remove it from public pages and Organization schema.
2. Replace any generated/placeholder photography with licensed or owned WebP images before launch.
3. Configure a restricted Google Maps Embed API key if you want API-based embeds rather than the no-key map fallback.
4. Add only genuine reviews, projects, credentials and provider claims.
5. Configure call tracking only after confirming the campaign attribution requirements.
